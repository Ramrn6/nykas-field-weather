# Nykas Field Weather

Live weather for your current location or any place: today hour by hour, rain outlook and 7-day rain map, rainfall so far this year against the 1991–2020 normal and last year, and the projected rainfall for the year.

Open: https://ramrn6.github.io/nykas-field-weather/ (add `#here` to go straight to your location).

Install as an app: on iPhone or iPad open the link in Safari, then Share › Add to Home Screen. On a Mac open it in Safari, then File › Add to Dock. The app opens full-screen, keeps the last forecast for use without a signal, and updates itself from this site.

Weather data by [Open-Meteo.com](https://open-meteo.com/) (CC BY 4.0).
