# Nykas Field Weather

Live weather for your current location or any place: today hour by hour, rainfall so far this year against the 1991–2020 normal and last year, and the projected rainfall for the year.

Open: https://ramrn6.github.io/nykas-field-weather/ (add `#here` to go straight to your location).

Weather data by [Open-Meteo.com](https://open-meteo.com/) (CC BY 4.0).
